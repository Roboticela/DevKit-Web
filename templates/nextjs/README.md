# Next.js + Prisma + PostgreSQL + SEO

Official Roboticela DevKit template. Bundled with the CLI — not fetched from GitHub.

## Stack

- Next.js 16 (App Router, RSC)
- React 19 + TypeScript
- Tailwind CSS 4
- Prisma + PostgreSQL
- SEO: metadata, sitemap, robots, Open Graph, JSON-LD helper

## After `devkit create`

```bash
cp .env.example .env
npm run db:push
npm run dev
```
